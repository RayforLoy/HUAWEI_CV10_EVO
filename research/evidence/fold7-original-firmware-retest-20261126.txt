All headset offsets below refer to the full DFU, with 0x525 mapped to 0x08020000.
0x91157 dispatches UVDM 0x0105 (serial) and 0x0106 (info) on the low header half-word.
0x910BB marks type 1, formats word 0 as four upper-to-lower %02X octets, then the low
byte of word 1 as %03d. It subtracts 2731 from word 2, formats the result as %04d,
and overwrites its leading character with the sign. 0x84E05 emits type + 8 + 3 + 4
characters. For type 0 the suffix is explicitly filled with 15 ASCII zeros.
Temperature 0x0BC3 gives 3011 - 2731 = 280 -> 0280 -> +280.
Temperature 0xFFFF gives 65535 - 2731 = 62804 -> +2804 -> +280 (first four characters).
Thus the AT string cannot discriminate these cases. Its last 0 belongs to the signed field.
The RAM command table reconstructed from 0xB9E51 using the decompressor at 0xB0F7D
maps TBATLVL, TBATVOLT, TBATTEMP, TBATCURRENT, TBATDATA?, VBUS? and IINLIMIT? to
0x8243F, which calls the response builder with four zero arguments and performs no measurement.

Transmitter (original C9.49.6, raw 8051 file offsets and XDATA addresses).
0x03C7 / 0x03F9 select serial/info, then 0x0917 builds the 2109:0105/0106 VDM headers.
For the info message 0x0408..0x0428 produce the version bytes. 0x0429..0x0455 insert
XDATA[2DFE] in payload word 1 and XDATA[2E01], XDATA[2E02] in the low two bytes of
word 2. The TX buffer is cleared before the packet is built (0x842D -> 0x95BA).
0xA188..0xA1B6 and 0x6329..0x6346 load these caches from I2C slave 55h: register 2Ch
for the level byte and 66h/67h for the temperature low/high bytes. 0xA1C8 onwards
compares the level with 40/60, then 30; it treats FF as numerically above 60 here.
0xA14A checks the temperature word and skips this over-temperature check on FFFF or 0000.
