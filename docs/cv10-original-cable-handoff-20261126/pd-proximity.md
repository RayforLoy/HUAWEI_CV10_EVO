## 电脑从接入起单独供电

11:45，眼镜端保持插紧，先拔电脑端及辅助充电头，等待后只把电脑端插回 XHC1。使用者确认镜片黑、线控蓝灯亮。头显回复 CV10 和原厂线 C9.49.6，11:45:16.464 报未佩戴；Windows 恢复 3200×1600、90 Hz。11:45:34.665 报已佩戴，发送开屏后读到空应答，11:45:34.676 事件串口失联。这次未获开屏确认，与独立 PD 电源下收到完整应答有所不同。右眼录像容器未写完帧索引，顺序解码的 9,733 帧中均未见测试色。[冷接线、镜片与 USB 证据](../../research/evidence/pc-original-host-power-20261126.txt)

这次掉线后仍能用 NVIDIA DDC 接口连续三次读回 **256 字节 EDID**。从 EDID 头对齐后，基础块和 CTA 扩展块各自校验通过，全部字节与 Windows 此前获得的 EDID 相同。11:46:08 USB 集线器第 2 口无头显控制设备，第 5 口 VIA HID 在线。第 1 口在正常时是音频，此时有设备尝试枚举但读取设备描述符失败，Windows 报 Code 43。随后对该失败端口尝试一次 Windows 端口重置，返回 Win32 错误 31。MCCS 的面板电源和亮度查询也未获得应答。能够读取显示身份、电脑保持原生时序和蓝灯亮，这三件事可与镜片黑屏、控制口失联同时发生。[Windows 集线器端口状态定义](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/usbioctl/ne-usbioctl-_usb_connection_status)

移除辅助电源没有消除佩戴触发的掉线。外接 PD 那轮故障后 DDC 读失败，电脑单独供电这轮仍能读，两个单次观测不足以将差异归因于电源。当前接线可读到的信息未包含眼镜端的带载电压、线内开关电平或 CC 报文。
